# Legionowo transit

Legionowo, a town next to Warsaw, runs free public bus lines. Their timetables are published
as text on the town's website and on some stops, but no map or app shows when the next bus
leaves a given stop.

This project puts those timetables on a map: pick a stop, see which lines leave it and in how
many minutes, and plan the trip before going out into the cold.

Status: idea stage. The product is shaped first, then built.

Open source under the MIT license.
